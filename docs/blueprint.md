# **App Name**: Mystiq Mind Landing

## Core Features:

- Animated Hero Section: Display a hero section with the app's name ('Mystiq Mind') with glowing neon animation at the top.
- Magical Orb Animation: Show a central magical orb animation (pulsing glow) above the download button to create a visually engaging focal point.
- Animated Download Button: Incorporate a large, animated 'Download Now' button with a gold glowing effect and sparkle on hover.
- Download Redirection: Set up the download button to redirect users to the direct Google Drive APK download link upon clicking (https://drive.google.com/uc?export=download&id=1QTwbATqvRxsfTK4gp1vsh00MWdSmXzwM).
- Responsive Design: Ensure the landing page is fully mobile-responsive, providing a seamless experience across various devices and screen sizes.
- Background Effects: Add smooth fade-in and floating particle effects in the background to enhance the mystical aura.

## Style Guidelines:

- Dark gradient background with a mystical aura using blue and purple glows (#120A8F to #4B0082).
- Glowing gold (#FFD700) for the download button to convey magic and value.
- Neon Blue (#13EAC9) to highlight the interactive parts of the page and draw attention.
- 'Poppins' (sans-serif) for a geometric and modern look, suitable for headlines and shorter text, lending a fashionable, avant-garde feel.
- Use a slightly smaller font size and a lighter shade to complement the title for the tagline.
- Glowing neon effect for the app name ('Mystiq Mind') to emphasize the mystical theme.
- Subtle fade-in animations for page elements to create a smooth user experience.
